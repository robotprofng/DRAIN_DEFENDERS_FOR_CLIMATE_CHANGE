# drain-defender# Drain Defenders 🌍

A website I built with two children to raise awareness about improper waste disposal, blocked drainage and flooding.

## About the Project

Drain Defenders explores how web development can be used to communicate environmental issues and encourage better waste disposal practices.

I worked on this project with two children, bringing technology and environmental awareness together to address a problem that affects our communities.

## Project Focus

- Environmental awareness and responsible waste disposal.
- The connection between blocked drainage and flooding.
- Using technology to communicate community problems.
- Building digital projects collaboratively with young people.
